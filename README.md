# vicen--obiol
Hola # 🚀 Proyecto Inicial – Metodología Profesional en IT

## 📌 Descripción del proyecto
Este proyecto marca el punto de partida de nuestra formación como profesionales del sector tecnológico. El objetivo principal no es desarrollar un producto técnico final completo, sino **aprender a trabajar con metodología profesional**, organización y trabajo en equipo, simulando un entorno real de empresa.

## 🎯 Objetivos
- Aplicar una **metodología de trabajo ágil y estructurada**.
- Aprender a gestionar tareas mediante **Kanban**.
- Desarrollar habilidades de **organización, constancia y responsabilidad**.
- Fomentar el **trabajo en equipo** y la resolución de conflictos.
- Consolidar conocimientos técnicos básicos en redes, sistemas y seguridad.

## 🧠 Metodología de trabajo
Trabajamos siguiendo principios ágiles:

- Uso de **Kanban** con herramientas como Microsoft Planner.
- Organización visual de tareas (pendiente, en proceso, finalizado).
- Trabajo iterativo y constante.
- Seguimiento y auditorías por parte del “cliente” (Proyecto Intermodular).

## 👥 Roles del proyecto
- **Proyecto Intermodular**: actúa como cliente (seguimiento, auditorías y soporte).
- **Módulos formativos**: proporcionan conocimientos y tareas (backlog).
- **Alumnos**: responsables de transformar el backlog en productos entregables.

## 🧩 Tareas del proyecto
Durante el proyecto se desarrollan las siguientes actividades:

- **T01**: Introducción a Kanban y gestión visual.
- **T02**: Creación de una empresa (emprendimiento).
- **T04**: Repaso de redes TCP/IP.
- **T05**: Comandos básicos de Linux.
- **T06**: Fundamentos de seguridad informática.
- **T07**: Seguridad física en empresas.
- **T08**: Introducción a la sostenibilidad (ASG).
- **T09**: Hosting, DNS y fundamentos web.

## 📦 Entregables principales
- **P01 – Kanban digital**  
  Tablero de gestión de tareas en Microsoft Planner.

- **P02 – Guía de instalación de Linux Server**  
  Documento técnico detallado del proceso de instalación.

- **Otros entregables**  
  - Presentaciones  
  - Mapas conceptuales  
  - Dossiers de ejercicios  

## 🤝 Trabajo en equipo
El proyecto requiere:
- Coordinación entre miembros del equipo.
- Reparto de tareas efectivo.
- Resolución conjunta de problemas técnicos.
- Gestión del “factor humano” (motivación, comunicación, conflictos).

## ✅ Claves del éxito
- Constancia en el trabajo diario.
- Organización y planificación.
- Cumplimiento de plazos.
- Actitud profesional.

## 🌱 Conclusión
Este proyecto es un primer entrenamiento para el mundo laboral real. Más allá del resultado técnico, el objetivo es desarrollar una mentalidad profesional basada en la metodología, la colaboración y la mejora continua.
